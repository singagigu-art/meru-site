meru

個人用のデスクトップ メールアプリ / A personal desktop mail client

このアプリについて

meru は、開発者本人が自分のメールを読むために作っている、Windows 用のメールアプリです。一般には配布していません。Gmail と Outlook のメールを、利用者の PC から直接読み書きします。

About

meru is a Windows desktop mail client built by its developer for personal use. It is not distributed to the public. It reads and writes the user's own Gmail and Outlook mail directly from the user's PC.
