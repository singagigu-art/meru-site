プライバシー ポリシー / Privacy Policy

meru　／　最終更新 2026-11-14

扱うデータ

meru は、利用者が自分でログインした Gmail と Outlook のアカウントについて、メール（差出人、件名、本文、添付、ラベル）を読み、既読・削除・送信の操作を行います。Gmail には Google の Gmail API を使います。

データの保存場所

取得したメールの情報とログインの情報は、利用者の PC の中にだけ保存します。ログインの情報は Windows の機能で暗号化します。開発者のサーバーは存在せず、データを開発者や第三者に送信することはありません。

データの利用目的

利用者本人にメールを表示し、本人の操作をメールサービスに反映するためだけに使います。広告、分析、機械学習モデルの学習、販売、第三者への提供には使いません。

Google の利用者データに関する方針

meru による Google API から受け取った情報の利用と他のアプリへの移転は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

データの削除

アプリのデータ フォルダーを削除すると、PC に保存したすべての情報が消えます。アプリへのアクセス権は、Google アカウントの設定からいつでも取り消せます。

English summary

meru is a personal desktop mail client. It accesses the Gmail and Outlook accounts that the user signs in to, in order to display mail to the user and to apply the user's own actions (mark as read, delete, send). Mail data and sign-in tokens are stored only on the user's own PC; tokens are encrypted with a Windows facility. There is no developer-operated server, and no data is sent to the developer or to any third party. Data is not used for advertising, analytics, training machine-learning models, or sale.

meru's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting the app's data folder removes all locally stored data. Access can be revoked at any time from the Google Account settings.
